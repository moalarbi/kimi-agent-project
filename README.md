# امدادات العطاء كونتكتس

دليل تحويلات وكونتكتس شركة امدادات العطاء - تطبيق ويب داخلي للبحث السريع عن جهات الاتصال.

## الميزات

- 🔍 بحث فوري بالاسم أو رقم التحويل
- 📱 تصميم متجاوب ومُحسّن للجوال
- 🎨 واجهة عصرية بتأثير الزجاج (Glassmorphism)
- 🌙 خلفية داكنة أنيقة
- ⌨️ دعم لوحة المفاتيح (Enter للبحث، Esc لمسح)

## كيفية التشغيل

### متطلبات التشغيل
- Node.js 18+
- npm

### خطوات التشغيل

```bash
# تثبيت التبعيات
npm install

# تشغيل في وضع التطوير
npm run dev

# بناء للإنتاج
npm run build
```

## تعديل بيانات جهات الاتصال

لإضافة أو تعديل جهات الاتصال، عدّل الملف:

```
src/data/contacts.ts
```

مثال على إضافة جهة اتصال جديدة:

```typescript
{
  id: "39",
  name: "اسم الموظف",
  ext: 999,
  dept: "القسم"
}
```
